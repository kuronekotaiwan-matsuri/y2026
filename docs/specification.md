# サイト仕様書: 黒猫台湾まつり2026

## 1. 概要

### サイトの目的
黒猫台湾まつり2026の公式ホームページ。台湾に関する食や小物の販売を行う地域のお祭りの情報発信・集客を目的とする。

### ターゲットユーザー
- 川崎市高津区周辺の地域住民
- 台湾文化に興味がある人
- 家族連れ、友人同士での来場者
- 報道関係者（プレスリリースページ）

### サイトのゴール
- イベントの認知拡大と来場促進
- 出店者情報の提供
- イベントの趣旨・魅力の発信
- 来場者の疑問解消（FAQ）

### 技術スタック
- Next.js（静的サイト生成）
- Static Export（`output: 'export'`）

### 3.2 イベントについて (`/about`)

#### セクション構成

1. **イベント趣旨セクション**
   - タイトル + リード文
   - 3つのテーマを画像付きで紹介:

2. **見どころセクション**
   - タイトル: 「楽しみ方いろいろ！黒猫台湾まつりの見どころ」

     - **物販ブース**: 台湾雑貨やフードの販売

## 6. 技術要件

### レスポンシブ対応
- モバイルファースト設計
- ブレークポイント: sm(640px), md(768px), lg(1024px)
- スマートフォンでの閲覧を最優先

### ブラウザ対応
- Chrome, Safari, Edge（最新版）
- iOS Safari, Android Chrome

### SEO
- 各ページにmeta title, descriptionを設定
- OGP（Open Graph Protocol）タグの設定
- Schema.org構造化データ（Eventスキーマ）
- sitemap.xmlの生成

### アクセシビリティ
- セマンティックHTML
- 画像にalt属性を設定
- キーボード操作対応
- 十分なカラーコントラスト比の確保

### アニメーション
- スクロール連動のフェードインアニメーション（軽量）
- アコーディオン・フィルターの開閉/切り替えアニメーション
- マウスホバーエフェクトは不要（モバイル優先のため）
- パフォーマンスに影響しない範囲で実装

### 画像
- 画像は仮のプレースホルダーを使用
- 実際の画像は後日差し替え前提

### デプロイ
- 静的エクスポート（`next export`相当）
- GitHub Pagesでのホスティングを想定
